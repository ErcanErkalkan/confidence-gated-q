# Non-degenerate sensorized closure protocol

This is a new the sensor nondegenerate closure diagnostic closure family. It preserves the prior
all-floor sensorized result and does not modify the original sensor-final lock.

The first phase tests three predeclared horizon/interaction candidates on the
same combined sensor condition under low- and high-level control interfaces.
The smallest candidate is selected only if the model-based reference shows
task feasibility, at least one learned cell has waypoint success between 0.05
and 0.95, and learned-cell success rates span at least 0.10. P-values are not
used. If no candidate qualifies, later development and final execution are
prohibited rather than rationalized from shaped return.

The second phase uses new development seeds. It repeats the eight isolated
sensor factors at one selected interface and repeats the temporal/capacity and
four-way interface design at the same budget. Temporal search counts remain
three versus three. The informative factor and temporal model are selected by
the exact non-p-value rules in the YAML.

Only after both selections are frozen may the 30-seed final family execute.
It compares combined sensorized low- and high-level interfaces and the selected
isolated factor. Zero-success, collision, null, and negative results remain in
the denominator. Waypoint success, not shaped return, is the primary endpoint.

All evidence remains software-in-the-loop. No practical-readiness, HIL, flight,
or safety-certification claim is permitted.
